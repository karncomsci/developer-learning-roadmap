# แยก Go API ออกจาก Next.js

ระบบมี Owner คนเดียว ถ้าให้ Next.js คุยกับ Postgres ตรง ๆ ก็พอ แต่เราเลือกแยก backend เป็น Go API ที่ deploy เองต่างหาก เพราะเป้าหมายของโปรเจคนี้คือได้ฝึกทั้ง frontend (Next.js) และ backend (Go) ราคาที่ต้องจ่ายคือมีบริการเพิ่มหนึ่งตัวที่ต้องหาที่ deploy ต้องมี JWT ระหว่างสองบริการ และต้องดูแลสัญญา OpenAPI ร่วมกันสองฝั่ง อย่า "ทำให้ง่ายขึ้น" ด้วยการรวมสองบริการเข้าด้วยกันโดยไม่ได้ทบทวนเป้าหมายข้อนี้ก่อน
