# กฎของโดเมนและการตรวจสิทธิ์อยู่ใน Go ที่เดียว

กฎของโดเมนทุกข้อ (slug, การห้ามวงของ Prerequisite, การตรวจชนิดรูป ฯลฯ) และการตัดสินว่าผู้เรียกเป็น Owner หรือไม่ อยู่ใน Go API เท่านั้น Next.js ใช้ session แค่เพื่อเลือกว่าจะแสดงหรือซ่อนปุ่มแก้ไข และไม่ทำการตรวจซ้ำ ที่เลือกแบบนี้เพราะต้องการให้มีแหล่งความจริงเดียว จะได้ไม่เกิดกรณีที่กฎสองฝั่งไม่ตรงกัน
