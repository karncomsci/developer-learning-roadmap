# เบราว์เซอร์คุยกับ Next.js เท่านั้น

เบราว์เซอร์ไม่เรียก Go API ตรง การอ่านข้อมูลทำผ่าน server rendering และการแก้ข้อมูลทำผ่าน Server Actions ซึ่ง Next.js ฝั่ง server จะสร้าง JWT อายุสั้นแนบไปเรียก Go ให้ ผลคือ Go ไม่ต้องตั้งค่า CORS ไม่ต้องเปิด token ให้เบราว์เซอร์เห็น และใช้ secret ร่วมแบบ HS256 ได้ ข้อจำกัดคือรูปที่อัปโหลดต้องผ่าน Next.js ก่อนถึง Go จึงติดเพดาน body 4.5 MB ของ Vercel (รูปประกอบอ่านตรงจาก URL สาธารณะของ Storage ซึ่งเป็นข้อยกเว้นเดียวของกฎนี้)
